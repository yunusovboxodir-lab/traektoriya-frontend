2026-07-27, соло-сценарий зоны E: замер прода — 128 юзеров, 99 ТП, входили 87,
но активные минуты >0 только у 9 из 99 (после фикса чёрного экрана 26.07,
[[project_blackscreen_root_cause_2026-07-26]] в общей памяти проекта). Задача —
пройти путь ТП живьём и найти, где теряется.

**Главный вывод:** маршрут логин → урок технически КОРОТКИЙ и РАБОЧИЙ, не
подтвердил гипотезу «UX-барьер в самом приложении». Для настоящего bronze-ТП
по коду: логин (1 клик) → авто-редирект на `/learning` (0 кликов) → тап по
курсу на карте (1 клик) → урок открыт. Механика урока (сценарная сцена
BlockCinematicScene, тайпрайтер-диалог) реально работает: клики продвигают
состояние, бэкстори/диалог корректно рендерятся. Ноль ошибок в консоли на всём
пути (логин/дашборд/карта/урок/задачи/профиль/RU/UZ/375px).

**НО ключевой методологический разрыв:** самый чувствительный шаг — редирект
после логина для настоящего bronze-пользователя — не подтверждён вживую,
потому что единственный доступный тестовый аккаунт (`seller1`) имеет
замоканный tier=gold (см. [[project-seller1-mock-scope-gotcha]]), из-за чего
вместо `/learning` он попадает на `/dashboard`. По коду фикс 26.07 выглядит
корректным (dashboard гейтится по `isTierGated`, bronze→`/learning` через
`getFirstAllowedPath()`), но живого подтверждения на реальном bronze-аккаунте
нет.

**Найденные реальные (не мок) дефекты этого прогона:**
1. 🟡 `src/components/dashboard/LearningRankWidget.tsx:159-161,600` — хардкод
   русских строк («50% обучение», «Обучение X · Активность Y · Streak Z» в
   native `title`) виден в UZ-режиме интерфейса. Мимо ESLint i18n-гейта
   проскочило, т.к. это шаблонная строка в `.ts`-вычислении, не JSX text node.
2. 🟡 `src/styles/tactical-design.css:1807-1818` — мобильные тап-таргеты
   языка/темы в StatusBar `min-height/width: 32px`, при этом комментарий в
   коде утверждает «гарантируем тап-зону 44px» — расхождение intent vs
   реализация. РУ/UZ кнопки впритык друг к другу без зазора.
3. 🟡 `PowerBadge` (popover с разбивкой Мощи Бизнес/Обучение/Достижения/Серия +
   формула) существует и хорошо отвечает на «почему у меня N» — но только в
   `StatusBar`, который НЕ рендерится на мобильной версии `/learning`
   (заменён на `TacticalMobile.tsx` с плоской некликабельной строкой). На
   телефоне (основной канал ЦА) узнать разбивку Мощи негде.
4. 🟡 Прямой заход на `/dashboard` может на мгновение увести на `/learning`
   из-за гонки загрузки tier (scopeStore трактует `null` как bronze) —
   воспроизведено (короткий wait → редирект, долгий wait → остался на месте).
   Актуально для deep-link из Telegram-бота.
5. 🔵 Коды курсов «СТ-01/ПР-01/ЭК-01/МР-01» кириллицей даже в UZ-интерфейсе
   (где уровни уже «STAJYOR/PRAKTIK...»).
6. Не воспроизведено (для протокола, не находка): один раз в сети мелькнули
   запросы `.../learning/course/undefined/api/v1/analytics/user/{uuid}» — 3
   попытки повторить не дали результата.

**Позитив, тоже важно:** пустые состояния сделаны хорошо (`/tasks` → явное
«Нет задач», не пустой экран/спиннер), мобильный layout `/learning` и
`/dashboard` не переполняется на 375px, тап-таргеты курсов/нижней навигации в
норме (59px+), i18n в целом качественный (RU/UZ параллелизм, ни одного сырого
ключа за всю сессию), сервер не пострадал от тестовых действий.

**How to apply:** при следующем прогоне (или когда появится настоящий bronze-
тестовый аккаунт) — в первую очередь проверить именно редирект логина для
bronze вживую, это единственное реально непокрытое звено в объяснении
«9 из 99». Если и там всё чисто — проблема оттока, видимо, ВНЕ веб-приложения
(мотивация/оффлайн-факторы/канал оповещения), не UX самого продукта.
